Launchpad 机制研究

普通 Launchpad 发的是 Token。TapeOut 想发出来的，是一套还能继续 Build 的生产系统。TapeHub 是这套系统上被简化过的发射口。

机制对照，不是收益预测，也不是官方文档。完整 Markdown 在仓库 RESEARCH.md。

1. 赌场盘在发什么

Pump.fun、Four.meme、Flap、Pons 的生命周期几乎同一条：创建 Token → Bonding Curve 买入 → 达标毕业 → AMM 流动性。这条路解决的是：怎么把一个 Token 在几十分钟里定价完。Four.meme 已经把 BNB Chain 上的发行做成了规模。问题不在「发得不够快」，在供给函数。

共同结构：价格发现和筹码释放叠在同一分钟。LP 锁不锁、税高不高，改的是抽池和狙击，不改「第一天就能砸完」。

2. TapeHub 现在的规则

  1. 发起人不能预留。
  2. 用户买的是晶体管，不是立刻能砸的全部筹码。
  3. 毕业时大约 5% 代币 + 募资约 99% 进永久锁仓 LP。
  4. 95% 必须靠矿机挖出来。每 5 个晶体管合成一台矿机。9 段减半，跨度 1908 天。
  5. NAND/LATCH 消耗 ≠ BEM 消耗。不要收成一句「通缩」。

买的是产币权。矿工每天兑现，是可计算的卖压。盘口薄的时候仍会把价格压下去——「现状慢熊」是默认路径。深度上来以后，同一套排放从打穿盘口，变成可吸收的通胀。

3. 两扇门

TapeHub · Launch： Mint 晶体管 → 毕业 → 5 个合成矿机 → 按减半表挖代币。不画电路，不对 PoD。

Protocol · Build： NAND / LATCH 是生产资料。自己设计、流片、迎合 PoD，元件被真实消耗，生成 Circuit。

完整链：Launch → Mint Components → Build → Tape Out → Circuit → PoD / Application / DeWEB。Launch 只是第一天。

4. Bancor / DeFi Summer

Bancor 把铸造、销毁和储备比率写成协议。DeFi Summer 把奖励摊到块。TapeHub 站在这条线上：赌场盘是注意力拍卖；TapeHub 把时间写进供给。机制保护的是下限，不是上限。

5. 和 Four.meme 的分工

发行、交易、深度，Four.meme 已经验证过了。TapeOut 出原生玩法，Four.meme / OpenFour 出基础设施。模拟器里的「TapeHub + Four.meme」只改一件事：供给函数不变，交易层变厚。合作是在谈的方向，不是已经签完的合同。Proof of Build 是畅想。

6. DeWEB

开发者一次上传、永久免费存。访问的人不需要钱包、不需要 gas，和 Web2 一样。多出来的是 Verification。
