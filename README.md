# Launch Lab · TapeOut Research

对照 Pump.fun、Four.meme、Flap、Pons、LONG、Virtuals 与 TapeHub 的发射机制，以及同一笔注意力下的代币走势模拟。

作者：[x.com/BruceBlue](https://x.com/BruceBlue)

**公开页面：** [brucelanlan.github.io](https://brucelanlan.github.io/)  
**机制研究正文：** [RESEARCH.md](./RESEARCH.md)

这是机制对照，不是收益预测。TapeHub 保护的是供给下限（无预留、5% LP / 95% 减半挖矿、1908 天），不是价格上限。

## 仓库里有什么

| 文件 | 内容 |

## 怎么看模拟器

1. 切「秒盘对照」看赌场盘 24 小时内怎么死。
2. 切「未来主叙事」看 TapeHub + Four.meme 深度路径。
3. 「机制对照」把 TapeHub Launch 和 TapeOut Protocol 两扇门分开。

## 本地打开

直接打开 `index.html`，或：
